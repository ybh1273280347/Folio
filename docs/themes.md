# Folio 主题

在“设置 → 外观 → 主题”选择浅色、深色或已保存的主题。“编辑配色”可调整背景、画布、文字、边框、交互状态、强调色、代码背景和选中背景。颜色立即应用并自动保留；填写名称后点击“保存主题”即可反复切换，同名保存会更新已有自定义主题。浅色和深色也允许同名保存并覆盖当前配色。

主题只保存配色，切换时不改变字体、字号、公式缩放、行宽、文档内容或批注颜色。恢复默认外观会清除浅色、深色的覆盖配色，恢复内置预设并切回浅色，同时保留另外命名的自定义主题。主题随其他外观设置保存在应用数据目录的 `preferences.json` 中。

浅色保留原有界面颜色。深色依据 [Anthropic 官方品牌配色](https://github.com/anthropics/skills/blob/main/skills/brand-guidelines/SKILL.md)，采用暖黑 `#141413`、米白 `#FAF9F5`、灰色 `#B0AEA5` 与陶土橙 `#D97757`；画布 `#20201E`、悬停 `#2D2C29` 和边框 `#3D3C38` 是为 Folio 补充的层次色。这是适配原生工作台的配色预设，并非 Claude 界面的逐像素复刻。Claude 的[官方外观设置说明](https://support.claude.com/en/articles/8887527-customizing-your-appearance-settings)也将主题和字体作为独立选项。

Markdown 内的块级代码与正文一起响应 Ctrl＋滚轮，保留默认 14px 正文对应 13px 代码的比例。代码字体仍可单独选择。PDF 导出复用同一字号和配色，深色导出同时绘制画布背景，避免浅色文字落在白纸上。已有 PDF 文档的页面内容保持原样。
