# Folio Android

Folio 的离线 Android Markdown 编辑器，按桌面版的混合编辑方式实现：正文直接编辑、点击公式修改 LaTeX、随时切换源码模式。Android 外壳负责系统文件选择、导出和分享；本地 WebView 中的 ProseMirror 编辑器负责文档编辑，KaTeX 负责公式排版，依赖和字体随 APK 打包。

## 公式兼容

| 类型 | 写法 | 允许内侧空格 |
| --- | --- | --- |
| 行内 | `$x$`、`$ x $` | 是 |
| 行内 | `\(x\)`、`\( x \)` | 是 |
| 独立公式 | `$$x$$`、`$$ x $$`，也支持多行 | 是 |
| 独立公式 | `\[x\]`，也支持多行 | 是 |

- 识别发生在 Markdown 转义之前，导入文件、粘贴及直接输入使用同一分隔符规则。
- 点击公式打开源码和预览，应用后保留原有分隔符和公式正文的空格。复制而来的双反斜杠围栏也能识别；普通矩阵中的 `\\` 换行不被压缩。
- 行内代码和代码块不识别公式。普通货币请写成 `\$5`；因为允许 `$ x $`，成对未转义的美元符号会按数学公式处理。
- 公式渲染失败时显示对应源码，整篇笔记仍可继续编辑。支持的 LaTeX 命令以 KaTeX 为准，不调用完整 TeX 编译器。
- 独立公式后保留可输入段落；长公式在自己的区域横向滚动。

## 使用

1. 安装 APK 后打开 Folio。点击左上角 Folio 查看本机笔记，可新建或打开 `.md` 文件。
2. 正文直接编辑；底部工具栏支持撤销、重做、标题、粗体、斜体、列表、代码块和公式。Markdown 表格支持编辑单元格和单元格内公式。
3. 顶部“源码”切换为 Markdown 文本，“阅读”关闭正文编辑。
4. 笔记逐次编辑后保存在应用本机存储中；“导出”可保存或分享 Markdown 文件。导入创建本机副本，导出时选择目标文件，不自动覆盖原文件。

标题独立于正文一级标题。源码模式保留原始文本；可视化编辑后会重新序列化 Markdown，列表符号、空行等格式可能规范化。公式节点保存其原分隔符与 LaTeX 内容。

## 荣耀 GT Pro 适配

- 按用户提供的 **1264 × 2800** 物理分辨率验证高清输出；布局由系统实际 CSS 视口和缩放决定，未硬编码物理像素为界面宽度。
- 正文最大行宽 740 CSS px；手机端保持边距、44 CSS px 最小控件触摸区域、长公式横向滚动。
- 支持浅色/深色、竖屏/横屏及键盘压缩后的布局；顶底栏考虑安全区域。
- 浏览器验收覆盖 320 px 窄屏、421 × 933 竖屏、933 × 421 横屏、421 × 430 压缩窗口，以及 2 倍密度的 1264 × 2800 截图。
- 浏览器尺寸测试不能代替荣耀真机的 MagicOS 输入法、手势导航和系统文件选择器测试。

## 实现边界

Markdown 文本是保存内容；ProseMirror 文档和 KaTeX DOM 是编辑/渲染状态。原生外壳只负责 Android 系统能力。桌面版 Rust/GPUI 代码独立保留，Android 代码集中在本目录。

当前交付范围是 Markdown 阅读与编辑，不含桌面版 LaTeX 工程编译、PDF 批注、原生终端和多分屏。通过单个 Markdown 文件导入的相对路径图片暂不包含其旁边的图片文件夹。应用数据清除或卸载会清除本机笔记，请通过导出保留文件备份。

## 开发验证

```powershell
cd android/web
npm ci
npm test
npm run test:ui
npm run build
```

UI 测试默认使用系统 Microsoft Edge；可通过 `FOLIO_BROWSER` 指定 Chromium 浏览器路径。Android 构建与桥接说明见 [README-native.md](README-native.md)。
