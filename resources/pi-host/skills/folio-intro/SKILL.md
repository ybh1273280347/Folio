# 介绍 Folio（面向普通用户）

> 给 AI：当用户想了解 Folio 时，用友好、直观、面向普通用户的语言介绍，重点讲清「能用来做什么」「从哪里进入」「怎么顺手操作」。

## 回答原则

1. **讲人话，不暴露技术实现**：
   - 不要提及编程语言、UI 框架、底层渲染/排版库、内部存储格式或文件路径（如 Rust、GPUI、WebView2、SQLite、JSONL、Pi SDK、配置目录、`%APPDATA%`、`.folio/`、`.pi/` 等）。
   - 不要把 AI 内部工具名（如 `folio_kb_search`、`folio_drawio_edit_cells`、`exa_search` 等）或代码/测试/构建命令念给普通用户，除非用户明确以开发者身份追问。
2. **先总览、再按需展开**：
   - 用户泛问“介绍一下 Folio”时：先用 1~2 句话讲清定位，再分模块概括核心能力与常见入口，最后附上 6~8 个最高频快捷键，并主动问用户想进一步了解哪一块（例如 Markdown 写作、LaTeX 编译、PDF 批注、知识画布、AI 助手或知识库）。
   - 用户只问某一方面时：聚焦该模块讲清入口、交互方式和注意事项，不必面面俱到。
3. **如实说明前置条件**：
   - 纯 Markdown 写作、PDF 阅读与批注、离线画图、知识画布和本地关键词搜索均为开箱可用；
   - 整篇 LaTeX 编译依赖本机已安装 TeX Live；AI 对话、联网搜索、划词翻译或扫描件高精度 OCR 需在「设置 → API 服务」等位置配置对应服务后使用。

## Folio 概览与能力要点（供组织回答时参考）

### 一句话定位
Folio 是一款轻量、启动快的 Windows 原生桌面写作与学习工作台，把 **Markdown 笔记**、**LaTeX 论文编译**、**PDF 阅读与批注**、**本地绘图与知识画布** 和 **AI 助手 / 个人知识库** 整合在同一个窗口里，适合日常记笔记、写论文和整理资料。

### 1. 工作区与文件整理
- **三种使用方式**：
  - **默认空间**：打开软件就能直接写笔记，适合随手记录。
  - **项目工作区**：按 `Ctrl + O` 或在左侧栏添加本地文件夹，按项目整理文档与资料（保留原本文件夹结构）。
  - **独立文件**：按 `Ctrl + Shift + O` 直接打开零散的 Markdown、LaTeX 或 PDF 文件。
- **左侧文件栏**（`Ctrl + \` 收起/展开）：
  - 点「新建」可创建 Markdown（`.md`）、LaTeX（`.tex`）、Draw.io 图表（`.drawio`）、文献库（`.bib`）或文件夹。
  - 文件会按类型显示彩色图标（笔记、常见代码、配置、Docker、Git 等）；常见代码、配置文件，以及 `Dockerfile`、`Makefile`、`.gitignore` 这类特殊文件名都能直接打开编辑，项目里的依赖与缓存目录会自动跳过。文件过大、含二进制内容或编码不受支持时，会提示无法作为文本打开。
  - 支持直接从系统文件夹**拖入文件**，或在聚焦文件树时 `Ctrl + V` 粘贴外部文件或剪贴板图片。
  - **废纸篓**：误删的文件会进入侧栏「废纸篓」保留 7 天，可随时恢复；文件树中也可按 `Ctrl + Z` 撤销删除。
  - **文件标签（Tag）**：提供 6 种颜色标签，方便跨目录分类和筛选。入口在侧栏「文件」标题栏的标签按钮、文件树右键菜单，或聚焦文件树按 `Alt + T`。
  - 标签面板会按标签列出文件数量：点击标签行即可筛选文件树，再点一次或点筛选条上的 `✕` 取消；把鼠标移到标签行末尾的「…」上（或右键）可以重命名、改颜色、删除，也能在面板里直接新建标签。
  - 文件行上的小标签同样点一下就筛选，显示不下的会收成「+N」，点开进入打标窗口：已选文件的标签用胶囊展示，部分文件已有时显示「已打/总数」，点 `+` 可应用到全部选中文件、点 `✕` 移除；在输入框里输入即可搜索，回车添加或新建标签，`↑↓` 选候选。
- **右侧分屏**：Markdown、文本 / 代码、PDF、网页、Draw.io 图和图片都能拖进右侧分屏对照查看；主编辑区还没有标签页时，分屏里打开的第一个文件会自动接管主编辑区。
- **Zen 专注模式**（`F11`）：一键隐藏左右侧栏、终端等辅助面板并全屏，只保留正文和大纲；再按 `F11` 或点「退出 Zen」恢复。

### 2. Markdown 混合写作与导出 PDF
- **双模式随时切**：支持所见即所得（可视化编辑）与源码模式，按 `Ctrl + /` 即时切换。
- **YAML 属性区**：如果文档开头用 `---` 写了 YAML 元信息（标题、日期、标签等），正文上方会出现一条属性区，文本、开关值和列表用不同样式显示，也能折叠成一行摘要；点「编辑 YAML」可就地修改，只改属性内容，正文和原有格式不受影响。
- **高效交互**：
  - 输入 `/` 呼出快捷插入菜单；选中文字会弹出格式与工具浮条；宽窗口下左侧自动显示文档大纲，点击标题即可跳转。
  - `Ctrl + F` 查找、`Ctrl + H` 替换（所见即所得模式下）。
  - 直接 `Ctrl + V` 粘贴截图会自动保存图片并插入文档；`Ctrl + 左键` 点击链接可跳转项目内文件或用浏览器打开网页；选中文字点工具条「译」可快速划词翻译。
- **丰富的排版能力**：
  - 原生支持行内与块级数学公式（点击块级公式可弹窗编辑）、Mermaid 流程图预览与缩放、可交互表格、代码块高亮与折叠、可折叠提示块与详情块。图表右上角的「查看大图」（阅读时单击、编辑时双击也可）会打开独立查看器：滚轮缩放、拖拽平移、双击在适应窗口和 100% 间切换，按 `Esc` 关闭。
  - 支持字体颜色（含自定义常用色）、荧光笔高亮，以及输入 `:` 快捷插入表情符号。
- 在源码、LaTeX 或代码编辑器里右键，会看到统一的 Folio 菜单（问 AI / 剪切 / 复制 / 粘贴 / 全选）；按 `Ctrl + Shift + L` 可把选中的文字（没选中则整个文件）直接发给 AI 助手继续追问。
- **矢量 PDF 导出**：一键将 Markdown 导出为 A4 分页的清晰 PDF，正文、公式与图表文字均可选中与复制。

### 3. LaTeX 论文编辑与编译
- 支持多标签编辑、语法高亮、查找替换与自动保存。
- 在顶栏选择主文件与编译引擎（XeLaTeX / pdfLaTeX / LuaLaTeX），按 `Ctrl + Enter` 即可开始或停止编译，在右侧分栏实时预览 PDF，右上角图标可查看完整编译日志。即使编译出错，也会保留上一次可用的 PDF 预览。

### 4. PDF 阅读、批注与图片查看
- **PDF 阅读**：支持目录跳转、侧边缩略图、全文搜索、缩放、文字复制与划词翻译，可配合分屏一边看文献一边做笔记。
- **5 色荧光高亮与批注**：在 PDF 中选中文字，或按住 `Alt` 拖拽框选，就能添加高亮并写下批注；右侧批注栏以卡片集中展示所有批注，点击卡片可跳回原文位置。
- **图片查看**：打开项目内图片后支持以鼠标为中心缩放（`Ctrl + 滚轮`）、`Ctrl + 0` 适应窗口、`Ctrl + 1` 原尺寸和拖拽移动。

### 5. 本地绘图与网页预览
- **离线 Draw.io 绘图**：在左侧栏「新建」选择 `.drawio`，即可使用内置简体中文离线画板画流程图、架构图等，支持自动保存并导出 PNG / SVG / PDF，也能直接让 AI 协助绘制或修改当前选中的图形。
- **HTML 交互预览**：打开本地 `.html` / `.htm` 文件可在应用内直接预览效果，并支持一键在默认浏览器中打开。
- **知识画布**：在左侧栏「新建」选择 `.canvas`，用节点和连线自由整理想法，也能一键切成水平或垂直思维导图。可把 Markdown 选中的文字或 PDF 批注「发送到画布」，点击节点就能跳回原文；打开文档时也能看到哪些画布引用了它。支持撤销重做、插入图片与导出 PDF / SVG / PNG，AI 也能帮忙创建、整理和自动排版。

### 6. 右侧功能中心：AI 助手、知识库与终端
右侧面板集中了主要效率工具，顶部支持直接搜索功能、命令与文件，也可拖拽调宽、最大化或查看运行中的任务。

- **AI 助手**（`Ctrl + Shift + A`）：
  - 按项目隔离，支持多标签并行对话，切换项目或关闭标签不会打断后台任务。
  - **便捷喂上下文**：可一键附加当前文件、引用编辑器或 PDF 里选中的片段、粘贴截图，或输入 `/` 开关当前上下文、压缩长对话、调用内置技能。
  - **丰富的协作能力**：AI 回答中划选文字会浮出「添加到对话」方便继续追问，回答也可一键导出为项目笔记；还可以直接让 AI 帮忙写 Markdown、画/改 Draw.io 图、给文档或 PDF 加批注、整理文件标签、检索项目知识库、批量编译 LaTeX，或按需联网检索与处理数据。
  - **权限可控**：涉及执行本地命令或脚本时默认弹出确认卡片，也可通过对话顶栏的盾牌图标切换授权模式。
- **本地知识库与 PDF 管理器**（打开项目后从右侧功能中心进入）：
  - **快速检索**：自动索引项目内的笔记与 PDF（包含未保存的草稿），输入关键词即可搜索并按书本卡片展示结果，点击直接跳到对应笔记位置或 PDF 页码。
  - **PDF 管理器**：查看各 PDF 解析状态、为扫描件补全文字识别，或把已解析 PDF 一键导出为 Markdown 笔记。
- **内置终端**（`` Ctrl + ` ``）：
  - 原生多标签 PowerShell 终端，复制/粘贴使用 `Ctrl + Shift + C / V`，隐藏面板后后台命令继续运行。

### 7. 个性化设置
在**「设置」**中可随时调整并即时生效：
- **外观**：浅色 / 深色 / 自定义配色（可保存多套方案）、背景图与透明度；界面、编辑器、Markdown 预览、AI 面板、终端字体、数学字体及中西文比例均可独立调节。
- **快捷键**：常用工作区与编辑快捷键均可在「设置 → 快捷键」中按个人习惯重新录制。
- **文件类型扩展**：如果某种代码或文本后缀没有出现在文件树，可在「设置 → 视图 → 额外文本文件白名单」里追加扩展名（逗号或空格分隔），保存后立即生效。
- **API 服务与扩展**：按需填写 AI 服务、翻译、联网搜索、OCR 等配置。

### 8. 常用快捷键速查（精选）
- `Ctrl + O`：打开项目文件夹
- `Ctrl + Shift + O`：打开独立文件
- `Ctrl + P`：查找项目内文件
- `Ctrl + \`：显示 / 隐藏左侧栏
- `Ctrl + /`：切换 Markdown 所见即所得 / 源码模式
- `Ctrl + Enter`：编译 / 停止编译 LaTeX
- `Ctrl + Shift + A`：打开 / 收起 AI 助手
- `Ctrl + Shift + L`：把选中内容或当前文件发送到 AI 助手
- `` Ctrl + ` ``：打开 / 收起终端
- `F11`：进入 / 退出 Zen 专注模式
- `Ctrl + 滚轮`：缩放编辑器字号、PDF 或图表
