# Folio 知识图谱与双链分析

> 给 AI：Folio 维护着覆盖 Markdown 笔记与 `.canvas` 知识画布的双链关系图谱。查结构、引用来源、孤立点或路径时，直接调用图谱工具，不要靠全文正则搜索或逐个读取文件猜测反链。

## 何时使用哪个工具

1. **查看全局结构与知识库体检 → `folio_graph_overview`**
   - 一次性获取当前空间的统计摘要（Markdown、Canvas、悬空双链、孤立笔记、连线数），以及按连接度排序的 `hubs`（核心枢纽）、`orphans`（零连接孤立笔记）和 `unresolved`（被引用但尚未创建的悬空路径及 `referenced_by` 来源列表）。
   - 适合回答：“帮我看看笔记库整体结构 / 有哪些孤立笔记 / 哪些概念经常被提到但还没写”。
2. **排查单篇文档的上下文与关联 → `folio_graph_neighbors`**
   - 传入 `path`（项目相对路径，如 `concepts/双链与知识图谱.md`）即可拿到：
     - `inbound`：谁引用了它（含 Markdown 引用行号 `line` 或 `.canvas` 锚点 `node_id`、链接文本 `label` 与标签）；
     - `outbound`：它引用了谁（含尚未创建的悬空目标）；
     - `two_hop`（传 `depth: 2` 时）：二跳关联节点及 `via` 桥接路径。
   - 如需阅读某条引用的上下文段落，拿到 `line` 后再定向读取对应文件该行附近即可，不必整库翻找。
3. **梳理两篇文档之间的脉络 → `folio_graph_path`**
   - 传入 `from_path` 与 `to_path` 查找最短连通路径及每一步的边类型（`markdown_link` / `canvas_anchor`）、方向（`outbound` / `inbound`）与定位信息。
   - 默认 `directed: false` 寻找无向最短语义路径；仅当需要严格沿“A 引用 B 引用 C”的引用方向追根溯源时设 `directed: true`。

## 协作与写回规范

- **参数与路径**：只传项目内相对路径（直接使用 `folio_graph_overview` 或用户上下文中的相对路径，不加磁盘盘符）；附件节点默认不计入统计，仅在用户专门询问图片或 PDF 引用归属时传 `include_attachments: true`。
- **补写双链格式**：若需要帮用户在 Markdown 文档中补充或新建链接，使用标准 Markdown 链接（如 `[标题](/目录/文件.md)` 根目录相对路径，或相对于当前文档的相对路径，含空格或特殊字符时做百分号编码），**不要写入裸 `[[标题]]` 文本**。
- **对外表达**：向用户总结图谱分析结果时，使用自然语言和可点击的文件引用（附上相关行号或画布名称），不向普通用户暴露内部工具名或底层数据库结构。
