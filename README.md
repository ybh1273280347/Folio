# Folio (GPUI)

基于 [GPUI](https://www.gpui.rs/) 与 Rust 编写的 Windows 原生 LaTeX / Markdown 个人工作台。

平时写文档和论文时，希望有一款轻量、启动快、内存占用低的本地编辑工具，于是用 GPUI 做了这套原生工作台：界面不依赖 Electron/Chromium，公式直接在进程内排版，PDF 导出也不用启动浏览器。把代码整理出来做一个简单的个人分享，供有类似需求或对 GPUI 开发感兴趣的朋友参考。

---

## 💡 设计特点

- **脱离 Web 运行时**：整个界面、编辑器与预览均基于 GPUI 原生渲染，不嵌入 Chromium、WebKit 或 CEF。
- **进程内数学公式排版**：Markdown 内嵌的 LaTeX 公式基于 `latex-rust` 盒模型在进程内解析与布局，直接由 GPUI 绘制字符字形与矢量横线，排版响应在亚毫秒级，无需生成中间 SVG 图片或拉起 Webview/KaTeX。
- **直接矢量 PDF 导出**：Markdown 导出 PDF 复用文档绘制操作并通过 `krilla` 输出，正文与公式均保留为可选择、可复制的矢量文字，无需调用无头浏览器（Headless Chrome）打印。
- **纯 Rust PDF 预览**：集成 `gpui-pdf` 实现 PDF 页面虚拟化、按需光栅化、目录导航、缩略图与高亮批注。
- **克制的资源管理**：
  - PDF 仅对当前视口附近的页面进行光栅化缓存，缩放或改变窗口时旧的未完成渲染任务直接丢弃；隐藏标签或关闭分屏即时释放资源。
  - 文件监听（`notify`）仅针对当前打开的文件比对哈希，仅在目录结构变动时重新扫描文件树。
  - 编辑器草稿状态随击键更新，避免定时全量轮询带来的性能抖动。

## ✨ 功能特性

### 1. LaTeX 编辑与编译
- 多标签页管理、语法高亮、行号、文本查找与替换、自动保存及外部修改冲突检测。
- 支持 XeLaTeX、pdfLaTeX、LuaLaTeX 编译器（调用本机 TeX Live）。
- 顶栏选择主文件与引擎，支持随时中止编译、查看完整构建日志，编译失败时自动保留上一次的 PDF 预览。

### 2. Markdown 混合编辑
- 支持所见即所得（WYSIWYG）与纯源码编辑模式，通过快捷键 `Ctrl+E` 即时切换。
- 支持标题、任务列表、粗斜体、表格单元格编辑、本地图片引用及文档大纲导航。
- 数学语法原生支持：`$...$`、`$$...$$`、`\(...\)` 和 `\[...\]`；点击块级公式可直接就地编辑 LaTeX 源码。
- 支持独立编辑分屏，满足双开对比需求。

### 3. PDF 预览与批注
- 连续滚动、页面跳转、多级缩放、目录树与侧边缩略图。
- 文本框选与复制，支持荧光高亮与本地批注管理。
- 每个分屏独立维护视图与滚动导航状态。

### 4. Markdown 导出 PDF
- 按当前编辑器正文宽度、字体设置和换行布局自动进行 A4 分页。
- 矢量字形内嵌，正文与公式中的文字均支持框选与复制，导出时不包含光标与编辑态元素。

### 5. 个性化设置
- **字体**：支持自定义界面字体、代码字体与 Markdown 正文字体。
- **数学字体**：内置/支持 STIX Two Math、Latin Modern Math、TeX Gyre Pagella Math，中文自动回退至系统字体（如微软雅黑）。
- **版面**：支持调节行内/块级公式缩放倍数、正文字号、行宽限制等，配置持久化存储。

## 🛠️ 构建与运行

### 前置环境

1. **操作系统**：Windows 10 / 11 (x86_64)。
2. **Rust 工具链**：推荐使用 GNU 工具链（`stable-x86_64-pc-windows-gnu`）并安装 MinGW-w64（确保 `gcc` 在 `PATH` 中）。
3. **TeX Live**（可选）：整篇 `.tex` 编译需要本机的 TeX Live 环境；纯 Markdown 编辑、预览与 PDF 导出无需安装 TeX 环境。

### 编译运行

在项目根目录下执行：

```powershell
# 编译并以发布模式运行
cargo run --release
```

如果需要打包便携发布目录：

```powershell
.\scripts\package.ps1
```
> 脚本将执行 Release 编译并将可执行文件、必要资源（字体、证书等）打包至 `dist\releases\`。

```text

├── vendor/               # 定制补丁模块（latex-rust 盒模型扩展、gpui-pdf、gpui-kit 等）

```
